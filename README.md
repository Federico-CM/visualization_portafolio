# Data Visualization Portfolio

This repository contains a curated selection of data visualizations created as part of my work in **data analysis and statistical modeling**, primarily using **R**.

The goal of this portfolio is to demonstrate my ability to:
- translate complex data into clear visual narratives,
- apply sound analytical thinking to real datasets,
- design reproducible and well-documented visual outputs.

---

## Tools & Techniques
- **R** (tidyverse, ggplot2, Shiny)
- Data cleaning & transformation
- Exploratory data analysis (EDA)
- Visual storytelling and communication
- Interactive dashboard development

### Peer-Reviewed Research Visualization

#### Spatial Distribution of an Emerging Wildlife Pathogen

![Spatial Distribution of an Emerging Wildlife Pathogen](https://raw.githubusercontent.com/Federico-CM/visualization_portafolio/main/plots/english/maps/choropleth/dendrobatidis.png)

This choropleth map was developed for a peer-reviewed epidemiological study investigating the distribution of *Batrachochytrium dendrobatidis* (Bd), a globally important pathogen. 

**Publication:**  
📄[Peer-reviewed EcoHealth article](https://doi.org/10.1007/s10393-020-01504-w)
